## 2026-10-27 - [Handle missing API key checks when `HINDSIGHT_API_SKIP_LLM_VERIFICATION` is enabled]
**Learning:** For test/CI scenarios, `HINDSIGHT_API_SKIP_LLM_VERIFICATION=true` or use of dummy values is typically provided to bypass LLM initialization checks. However, multiple provider abstractions (`LLMProvider`, `MemoryEngine`, `OpenAICompatibleLLM`, etc.) enforce structural validation for secrets (e.g. `HINDSIGHT_API_LLM_VERTEXAI_PROJECT_ID`, `api_key` for `openai` etc) directly in their `__init__` methods before `verify_connection()` is ever called.
**Action:** When working on backend initialization, conditionally disable strict credential validations in provider `__init__` loops if either `self._skip_llm_verification` (or its underlying global config/env var `HINDSIGHT_API_SKIP_LLM_VERIFICATION`) is true, or if `provider == "mock"`.
