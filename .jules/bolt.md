## 2026-05-19 - Replace numpy.exp with math.exp for scalar operation
**Learning:** Using heavy dependencies like `numpy` for single scalar math operations introduces significant overhead due to Python-to-C conversions, especially in hot paths like the `_sigmoid` function in the reranker. Standard library functions like `math.exp` are faster for these operations. However, `math.exp` doesn't automatically handle overflow for large negative inputs like `numpy.exp` does, so `OverflowError` must be caught explicitly.
**Action:** Always prefer standard library functions (e.g., `math.exp`) over heavy dependencies (e.g., `numpy.exp`) for single scalar operations to prevent Python-to-C conversion overhead. Ensure exceptions like `OverflowError` are handled gracefully when switching from `numpy` to `math`.
