## 2026-09-12 - Replaced numpy.exp with math.exp for scalar sigmoid in reranking
**Learning:** Using `numpy.exp` for scalar operations introduces significant overhead due to Python-to-C conversion. The application's `_sigmoid` function in `hindsight_api/engine/search/reranking.py` processes cross-encoder logit scores one by one, where `numpy` overhead dominates computation time.
**Action:** Replace `numpy.exp` with `math.exp` in Python hot paths doing single scalar operations. Wrap `math.exp` in a `try/except OverflowError` block, because unlike `numpy.exp` which returns 0.0 or inf for large magnitudes, `math.exp` will raise an `OverflowError` (e.g., highly negative logits causing `exp(-x)` to overflow, resulting in a sigmoid of 0.0). Also removed `import numpy as np` from `hindsight_api/engine/search/reranking.py`.
